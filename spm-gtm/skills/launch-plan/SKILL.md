# 新品上市计划（Launch Plan）

## 何时使用
- 新品确定上市窗口后制定完整 GTM 方案
- 上市中期检查节奏是否偏航
- 复盘上一次上新

## 核心模型：种草线与转化线双轨

护肤品上新不是"上架即发布"，而是内容蓄水与销售承接两条线的合拍：

- **种草线**（认知与信任）：小红书铺量测评 → 腰部达人背书 → 头部达人/专业向背书（皮肤科医生/配方师人设）
- **转化线**（承接与放大）：店铺自播常态化 → 付费流承接搜索 → 达人直播间打爆 → 大促收割

**关键纪律：搜索承接先于投放放量**。种草起量后用户会去平台搜，此时详情页、评价体系、搜索卡位没准备好=白烧钱。检查顺序：详情页转化要素齐备 → 前 100 条评价健康 → 搜索词卡位 → 再放种草量。

## T-90 倒排模板（以上市日为 T0）

| 时间 | 动作 |
|---|---|
| T-90 | 货品线：大货排产确认、备案号落袋；内容线：卖点体系定稿（ingredient-story 产出）、素材拍摄 brief |
| T-60 | 达人建联与寄样（测评期长的品类更早）；详情页初版；店铺承接页规划 |
| T-45 | 素人/尾部笔记铺量开始（自然舆情池）；主视觉与首图 A/B 备选完成 |
| T-30 | 腰部达人内容陆续发布；店铺上架（可暗上）做基础销量与评价；客服话术培训 |
| T-14 | 搜索词投放开启承接；直播间排期锁定；KOL 直播机制谈定（见 kol-brief） |
| T-7 | 全渠道物料终检（价格一致性!）；风险预案演练（差评/断货/舆情） |
| T0-T14 | 上市爆发期：头部内容+直播集中释放，日监控转化数据 |
| T+30 | 首月复盘：种草效率（CPE）、转化率、评价关键词、复购首购比 |

## 上市目标设定（分层）
- 北极星：首月 GMV 或首月新客数（二选一，别都要）
- 过程指标：内容曝光/互动、搜索指数增幅、详情页转化率、客单价、退货率
- 健康度红线：退货率 >15%、差评率 >3% 时暂停放量先修产品/预期管理

## 冷启动预算分配参考（新品牌）
内容种草 40-50% / 付费流量 25-35% / 达人佣金与坑位 15-25% / 预留机动 10%。老品牌有私域和会员资产时，首发向老客发售倾斜（私域首发价）能低成本做出首批评价。

## 注意事项
- 一次上新只打一个卖点一个人群，上市期内不换叙事——数据不好先查执行再怀疑定位
- 小样/中样是护肤品独有杠杆：派样拉新、正装转化、囤货凑单三种用法预算分开算
- 上市日期避开自身品类的大促静默期（大促前 2 周流量被平台虹吸）
- 断货是甜蜜的灾难：爆发期断货 >7 天，搜索热度回落等于重新上市，补单决策链路提前压到 48h 内
