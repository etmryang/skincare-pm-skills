# 大促规划（Campaign Planning）

## 何时使用
- 618 / 双11 / 38节 / 双12 等大促的整体方案
- 大促目标拆解与资源排布
- 大促后复盘

## 大促三段论

### 1. 蓄水期（大促前 3-5 周）
任务是攒"可收割资产"，不是卖货：
- 内容蓄水：种草笔记与短视频集中投放，把品牌词/产品词搜索热度顶上去
- 人群蓄水：加购/收藏/会员招募/直播间关注，各平台的人群资产（如加购人数）是爆发期投放的燃料
- 机制预告：预售/定金玩法教育，老客私域提前锁单
- **日销保护**：蓄水期不放价，用赠品预告对抗"等大促"观望

### 2. 爆发期（预售+现货开卖）
- 首小时冲刺：预售开门红决定平台资源位分配，前 2 小时投放预算占比最高
- 直播排期：自播拉长时+达人场次卡开卖节点
- 实时作战：库存水位、竞品价格、投放 ROI 三张实时表，预案触发条件写死（如"某 SKU 售罄 → 关联款顶上首页"）

### 3. 返场与复盘（大促后 1-2 周）
- 返场承接：未付尾款召回、售后与物流舆情盯守（大促差评高峰在收货后 3-7 天）
- 复盘按"人货场钱"四账对齐

## 目标拆解公式

```
GMV 目标 = 流量 × 转化率 × 客单价
流量 = 免费（搜索/推荐/会员） + 付费（投放） + 达人
```

自检：分解后的每个因子对比日常值的倍数是否现实（大促转化率通常为日常 1.5-3 倍，流量翻倍靠钱——钱够吗？）。倒着算出"要花多少投放费才能达标"，毛利兜不住就砍目标，不要用亏损冲 GMV 换排名（除非战略性投入且提前定好上限）。

## 货品结构规划（护肤品特色）

| 角色 | 品 | 任务 |
|---|---|---|
| 引流款 | 明星单品中样/体验装 | 拉新，可微亏 |
| 利润款 | 正装+囤货装 | 挣钱主力 |
| 客单款 | 礼盒/套组（水乳精华组合） | 抬客单，套组价 < 单买总和但毛利仍优于打折 |
| 防御款 | 对位竞品机制的狙击组合 | 不让用户因机制流失 |

赠品阶梯：满 X 赠小样 → 满 2X 赠中样 → 前 N 名赠正装,用赠品做满减杠杆而非现金直降（保价盘）。

## 大促日历纪律
- 全年大促参与度提前规划：全力打 2 个（如 38+双11），其余轻度跟随——每促全力的品牌日销必然萎缩
- 大促机制与日销价差控制在用户可接受范围，避免"大促后价格背刺"舆情（价保申请是差评源）

## 复盘模板
1. 四账对齐：目标 vs 实际（GMV/新客/毛利/退货率）
2. 蓄水效率：蓄水期投入 → 爆发期转化的人群流转率
3. 货品复盘：各角色款是否完成任务，套组渗透率
4. 三条最贵的教训 + 下次大促的三个改变

## 注意事项
- 预售品的发货时效承诺要与供应链确认后再上机制，延迟发货是平台处罚+差评双杀
- 大促期客服接待量 3-5 倍于日常,提前扩容并演练标准话术（尤其价保、赠品缺货）
- 数据口径统一：下单 GMV vs 结算 GMV vs 退款后净 GMV，对内汇报用哪个提前定死
