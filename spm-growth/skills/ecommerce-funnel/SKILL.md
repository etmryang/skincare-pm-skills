# 电商转化漏斗分析

## 何时使用
- 单品转化率低于品类均值，定位卡点
- 上新期/大促期的日度数据诊断
- 详情页改版前后的效果评估

## 护肤品标准漏斗

```
曝光 → 点击（进店/进详情） → 深度浏览 → 加购/收藏 → 下单 → 支付 → 收货留存（不退货） → 复购
```

各环节主责与典型卡点：

| 环节 | 指标 | 主责因素 | 典型卡点信号 |
|---|---|---|---|
| 曝光→点击 | CTR | 首图、价格标签、标题卖点词 | CTR 低于品类均值：首图没有 3 秒记忆点/人群跑偏 |
| 点击→深浏览 | 停留时长、跳出率 | 首屏信息与流量来源的承接一致性 | 秒跳高：投放素材承诺与首屏对不上 |
| 深浏览→加购 | 加购率 | 卖点说服力、证据、价格锚 | 看完不加购：证据链断（见 ingredient-story） |
| 加购→支付 | 支付转化率 | 优惠券清晰度、评价区、客服响应 | 加购高支付低：在等大促，或问大家里有劝退回答 |
| 支付→留存 | 退货率 | 肤感预期管理、物流、包装 | 退货率高：详情页过度承诺或包装破损 |

## 诊断工作流
1. 拉数据：近 30 天分渠道（搜索/推荐/付费/达人）的各环节转化率
2. 对标：与品类均值、自己历史同期、竞品（可得时）三方对比，找**最大偏离环节**
3. 归因：该环节主责因素逐个排查（用上表），交叉流量来源看——搜索流量转化好而推荐流量差 = 人群问题不是页面问题
4. 一次只改一个变量，改后观察 ≥7 天（护肤品决策周期长，隔天看数据会误判）

## 护肤品特有的分析要点
- **问大家/评价区是隐形详情页**：转化异动先看最近 3 条追评和新增问答，一条"用了闷痘"的高赞回答能砍 20% 转化
- **搜索词-详情页匹配**：搜"敏感肌精华"进来的人首屏要立刻看到"敏感肌"三个字，通用首屏浪费精准流量
- **价格带跳失**：详情页比价行为普遍，被同价位竞品截流时看竞品对位（防御性内容：为什么我们贵 30 元）
- **大促前假性下跌**：大促前 2 周转化自然下滑（观望），别在此期间误判改版

## 输出模板
诊断报告：漏斗全景表（vs 基准）→ 最大卡点环节与证据 → 归因假设排序 → 本周 Action（一条）→ 观察指标与回看日期。

## 注意事项
- 转化率要分新老客看：老客复购拉高的总转化率会掩盖新客转化恶化
- 免费搜索转化率是产品力的最诚实指标（付费可以买来精准人群），长期跟踪它
- 数据颗粒度：单日数据噪音大，用 7 天滚动均值下结论
