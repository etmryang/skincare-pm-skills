# 社媒聆听（小红书/抖音/评论区）

## 何时使用
- 立项前：验证赛道热度、找未被满足的表达
- 卖点开发：从用户原声中提炼"人话卖点"
- 上市后：监测口碑风向、负面预警

## 数据源与各自偏差
| 平台 | 能看到什么 | 偏差提醒 |
|---|---|---|
| 小红书搜索联想词 | 真实需求的措辞方式 | 被投放笔记污染，注意区分素人/商单 |
| 小红书评论区 | 比笔记正文更真实的疑虑 | "蹲一个反馈"=观望人群的顾虑 |
| 抖音评论区 | 价格敏感度、信任疑虑 | 情绪化表达多，需去重 |
| 天猫/京东问大家 | 购前最后一道疑虑 | 最接近转化卡点，权重最高 |
| 电商差评 | 翻车场景、物流/包装问题 | 区分产品问题 vs 预期管理问题 |
| 什么值得买/知乎 | 成分党的技术性质疑 | 样本偏专业，勿当大众声音 |

## 分析框架：原声四分法

把抓到的用户原声（建议 ≥200 条）分入四桶：

1. **困扰表达**：她怎么描述问题（"烂脸""下巴闭口崩了"）→ 决定内容选题和搜索词投放
2. **效果期待**：她想要什么结果（"想要玻璃提拉感""素颜能看"）→ 决定卖点主张
3. **疑虑清单**：她怕什么（"会不会闷痘""孕妇能用吗""是不是智商税"）→ 决定详情页 QA 和客服话术
4. **比较基准**：她拿什么对比（"和 XX 精华比怎么样"）→ 决定竞品对位策略

## 执行步骤
1. 定义搜索词库：品类词 + 困扰词 + 成分词 + 竞品词，各 5-10 个
2. 每个词抓取热门内容的正文与高赞评论，标注来源与日期
3. 按四分法打标，统计各桶内高频表达（保留原话措辞，不要翻译成 PM 语言）
4. 产出：原声表达 Top20 榜单 + 措辞对照表（我们说的 vs 她们说的）

## 措辞对照表示例
| PM 语言 | 用户原声 |
|---|---|
| 维稳修护屏障 | 烂脸期救星 / 换季不作妖 |
| 改善肤质粗糙 | 摸起来像剥壳鸡蛋 |
| 控油调理水油平衡 | 下午不脱妆 / T 区不反光 |

## 注意事项
- 商单笔记识别：统一话术、集中发布时间、评论区无真实追问——剔除后再统计
- 原声引用注意脱敏，不要在对外材料中带用户 ID
- 声量 ≠ 销量：抖音爆词可能是猎奇而非购买意向，用电商搜索词交叉验证
- 竞品负面是机会清单：竞品差评里的"如果……就好了"是现成的产品定义输入
