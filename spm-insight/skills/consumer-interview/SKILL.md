# 护肤品消费者访谈

## 何时使用
- 新品概念验证前的深访（n=8-12）
- 上市后复盘"为什么买/为什么不复购"
- 分析已有的访谈录音稿/纪要

## 核心原则
1. **问过去的行为，不问未来的意愿**。"你会买吗"的回答没有价值；"你上一次买精华是什么时候、怎么决定的"才有。
2. **让她拿出化妆台**。视频访谈请对方展示正在用的产品，实物比记忆诚实——瓶身新旧、用量深浅都是数据。
3. **追问归因链**：困扰 → 她认为的原因 → 她试过的方案 → 为什么放弃 → 现在的妥协。

## 访谈脚本结构（60 分钟）

### 开场（5 min）
自我介绍、录音授权、"没有对错答案"。

### 第一幕：护肤现状盘点（15 min）
- 带我过一遍你早上/晚上的护肤流程，每一步用的什么？
- （对每个产品追问）这个用多久了？第几瓶？怎么知道它的？
- 最近一次全流程做完是什么时候？跳步骤时跳掉哪些？（暴露真实 vs 理想流程）

### 第二幕：最近一次购买复盘（15 min）
- 最近一次买护肤品是哪次？从"想买"到"下单"隔了多久？
- 中间搜过什么、看过谁的内容、比较过哪些竞品？
- 下单那一刻是什么触发的？（价格、直播间、临期焦虑）

### 第三幕：困扰与放弃史（15 min）
- 现在最想解决的肌肤问题是什么？为它花过的最贵的一次钱？
- 有没有买了没用完的产品？为什么停用？（翻车史=需求金矿）
- 如果明天这个问题消失了，生活会有什么不同？（挖情绪价值）

### 收尾（10 min）
- 概念卡测试（如有）：只读概念，先记录第一反应再追问
- 滚雪球：身边有没有护肤习惯跟你很不一样的朋友？

## 护肤品专用追问库
- "温和"具体指什么？（不刺痛 / 无香精 / 孕妇可用——每人定义不同）
- 你说"有效果"，是照镜子看到的还是感觉到的？多久注意到的？
- 这个价格你觉得贵吗？和什么比？

## 访谈分析输出
分析纪要时输出：
1. **行为事实清单**（只列可验证行为，标注原话出处）
2. **需求-妥协对**：她想要 X，但现在用 Y 妥协，因为 Z
3. **购买触发器**与**放弃触发器**各 Top3
4. **反常识发现**（与团队预设相反的证据）
5. 对概念/产品定义的修改建议

## 注意事项
- 单人访谈不出结论；模式需在 ≥3 人身上重复出现才记为发现
- 警惕"成分党表演"：有人会说术语显专业，用化妆台实物核对
- 敏感肌话题涉及医疗边界，用户提到皮肤病治疗时不给建议、只记录
