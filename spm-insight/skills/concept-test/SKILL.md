# 护肤品概念测试

## 何时使用
- 立项有 2-4 个候选方向，需要低成本分出高下
- 配方还没打样，先验证"说法"是否有人买单
- 上市前用概念卡预演详情页首屏

## 概念卡模板（单张 ≤120 字）

```
【人群困扰】换季一到，敏感肌又干又痒还泛红，修护产品要么太油要么没效果。
【方案】XX 舒缓精华：2% 神经酰胺复配积雪草，无香精无酒精，质地清爽秒吸收。
【承诺】7 天泛红可见改善，敏感肌全周期可用。
【价格锚】30ml / 179 元
```

四要素缺一不可：困扰（她的语言）、方案（差异点）、承诺（可感知效果+时间）、价格锚。**没有价格的概念测试无效**——护肤品的"喜欢"必须在价格约束下测。

## 测试方法选择
| 方法 | 成本 | 适用 |
|---|---|---|
| 问卷概念测试（n≥150/概念） | 低 | 3-4 个方向初筛 |
| 假门测试（投流到落地页测点击/留资） | 中 | 验证真实点击意愿，比问卷诚实 |
| 深访概念卡环节 | 中 | 理解"为什么"，配合问卷用 |
| 小红书素人笔记试水 | 中 | 测内容角度，同时看评论区疑虑 |

## 问卷核心题目（顺序固定）
1. 第一印象：看完概念，你的第一反应是什么？（开放题，放最前防污染）
2. 独特性：与你知道的产品相比，这个概念是否新鲜？（5 级）
3. 可信度：承诺的效果你信吗？哪句最不信？（5 级+开放）
4. 购买意愿：这个价格下你会购买吗？（5 级）
5. 价格感知：你觉得它应该卖多少钱？（开放，看锚点偏离）
6. 替换意愿：它会替换你现在用的哪个产品？（**关键题**——答不出替换对象=没有真实需求）

## 判断标准
- 购买意愿 Top2（肯定会+可能会）≥ 40% 且可信度 ≥ 3.5：可推进
- 独特性高但可信度低：卖点超前，降承诺或补证据（临床/测试数据）
- 购买意愿高但价格感知显著低于定价：价值传递不足，不是需求问题
- 各概念得分接近时，看**开放题的情绪强度**而非均分——有人骂有人爱的概念好过全员无感

## 注意事项
- 概念之间只变一个变量（人群/成分故事/承诺强度），否则测不出归因
- 承诺写法必须先过功效宣称合规（参见 spm-regulatory 的 claim-compliance），别测一个法规上不能说的卖点
- 假门测试留资后要给交代（如发放试用装名额），避免消耗品牌信任
