# 护肤品用户画像（Skin Persona）

## 何时使用
- 新品立项前定义目标人群
- 投放前给媒介/达人团队圈定人群包
- 复盘"买的人和我们以为的人是不是同一群人"

## 核心维度（区别于互联网画像）

护肤品画像不以"年龄+职业"为主轴，而以以下四层递进：

### 1. 肌肤基础层
- **肤质**：干皮 / 油皮 / 混合皮（混干偏 T 区油 vs 混油）/ 敏感肌（是否屏障受损）
- **肌肤困扰**（按优先级排序，最多 3 个）：泛红、闭口、痘痘、暗沉、细纹、干燥起皮、毛孔粗大、色斑
- **困扰的诱因认知**：用户自己归因于什么（熬夜、口罩、换季、医美后）——归因决定她搜什么词

### 2. 护肤成熟度层（决定沟通语言）
| 等级 | 特征 | 有效沟通方式 |
|---|---|---|
| 小白 | 只认品牌和功效词，"补水""美白" | 场景+效果承诺，不讲成分 |
| 进阶 | 认识明星成分：烟酰胺、玻色因、A醇 | 成分+浓度+搭配禁忌 |
| 成分党 | 看全成分表、查配方结构、看文献 | 配方逻辑、缓释技术、临床数据 |
| 专业向 | 医美用户/皮肤科背景 | 修护机制、术后适配性 |

### 3. 消费行为层
- 价格带接受度：单品心理价位区间（如精华 100-200 / 200-400 / 400+）
- 决策路径：小红书搜索型 / 抖音兴趣激发型 / 李佳琦式信任代理型 / 线下 BA 引导型
- 品类替换周期：正装用完周期、是否囤货、是否大促才买
- 品牌关系：国货偏好 / 国际大牌信仰 / 无品牌忠诚只认成分

### 4. 场景与情绪层
- 使用场景：早 C 晚 A、医美术后修护、换季急救、婚前冲刺、军训晒后
- 情绪动机：焦虑缓解型（怕老）、奖赏型（对自己好）、社交型（素颜自信）

## 输出模板

每个画像输出一页卡片：
1. **一句话人设**（例："25 岁混油敏皮成分党，早 C 晚 A 翻车后寻求温和替代"）
2. 四层维度填表
3. **她的搜索词**（5-8 个真实搜索词，如"A醇 爆皮 怎么办"）
4. **她不买的理由 Top3**（价格锚点、成分顾虑、品牌信任）
5. **触达组合**：平台 × 内容形式 × 达人层级

## 注意事项
- 画像最多 3 个，主画像占预期销量 60% 以上；超过 3 个说明产品定义没做完
- 每个维度要能回答"这个信息改变我们哪个决策"，答不出就删掉
- 用平台真实数据校准（小红书搜索联想词、生意参谋人群画像、评论区自述），不要闭门造车
