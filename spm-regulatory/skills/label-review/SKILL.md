# 标签审核（Label Review）

> ⚠️ 依据《化妆品标签管理办法》框架整理，印刷前请法规岗终审。

## 必标项清单（销售包装可视面）
- [ ] 产品中文名称（与备案/注册一致，含商标名+通用名+属性名结构）
- [ ] 备案人/注册人、生产企业名称与地址；境内责任人（进口品）
- [ ] 生产许可证编号（国产）；产品执行的标准编号
- [ ] **全成分表**：以"成分："引出，按含量降序；≤0.1% 的成分在"其他微量成分"中另行标注
- [ ] 净含量（字号有最低要求，与可视面面积挂钩）
- [ ] 使用期限：生产日期+保质期，或生产批号+限期使用日期
- [ ] 使用方法、必要的安全警示语（如需避光、儿童勿触、误入眼冲洗等）
- [ ] 特殊化妆品注册证编号（如适用）；功效宣称所必要的标注

## 高频打回点
1. **名称违规**：产品名含不能宣称的功效词（名称里的"美白"也算宣称）；"医""药""生物活性"等词受限
2. **成分排序错误**：与备案配方表不一致；香精按"香精"标注而写成具体香料名（或反之与备案不符）
3. **字号与面积**：净含量字号不达标；小规格包装（如小样）豁免项用错
4. **小样/中样标签**：赠品小样同样需合规标签（名称、备案人、使用期限），"非卖品"不豁免
5. **暗示性图案**：包装上的医疗器械形象、和医疗机构联名视觉、白大褂形象等构成暗示
6. **外文问题**：进口品无中文标签、外文宣称超出中文备案范围

## 标签与其他物料的一致性矩阵
| 内容 | 必须一致的来源 |
|---|---|
| 产品名称 | 备案/注册信息 = 包装 = 详情页 = 开票名称 |
| 功效宣称 | 备案宣称范围 ⊇ 包装 ⊇ 详情页/直播话术 |
| 全成分 | 备案配方 = 包装成分表 = 详情页成分表（美丽修行等平台会被用户比对） |
| 净含量/规格 | 包装 = 详情页 = 平台商品资质 |

**用户会拿美丽修行 App 对着你的包装查**——成分表任何不一致都会变成公关问题，不只是合规问题。

## 审核工作流
1. 收集三样：备案信息截图、包材刀版稿、详情页文案
2. 跑必标项清单逐项打勾
3. 跑一致性矩阵找差异
4. 输出：❌必须修改（法规风险）/ ⚠️建议修改（口碑风险）/ ✅通过，附具体条目定位（第几行/哪个面）

## 注意事项
- 刀版稿审核要看"实际印刷尺寸"下的可读性，字号缩水是隐形雷
- 限期使用日期的赋码方式（喷码位置）在审稿时就确定，别到灌装线上才发现没地方喷
- 电商专供不同规格时，每个规格都是独立标签审核对象
