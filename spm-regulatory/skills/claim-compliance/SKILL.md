# 功效宣称合规检查

> ⚠️ 以《化妆品功效宣称评价规范》《广告法》及平台规则现行版本为准，重大投放前过法务/法规审核。

## 核心逻辑
中国实行**功效宣称有据可依**制度：你宣称什么功效，就要有对应级别的证据，且摘要需公开可查。宣称不是文案问题，是"证据买没买"的预算问题。

## 功效分类与证据要求（PM 速查）

| 宣称类型 | 证据要求 | 备注 |
|---|---|---|
| 清洁、卸妆、香化、修饰类 | 可豁免评价 | 最轻路径 |
| 保湿、护发 | 文献/研究数据或试验均可 | 常规路径 |
| 舒缓、控油、去角质、紧致、抗皱、修护等 | 人体功效试验/消费者测试/实验室试验（按细则） | 抗皱、修护等部分必须人体试验 |
| **祛斑美白、防晒、防脱发** | 必须人体功效试验 + 特殊化妆品注册 | 最重路径 |
| 温和（无刺激）、量化宣称（"7天见效""降低50%"） | 需对应试验支持 | 量化词=量化证据 |

**PM 决策口诀**：先定卖点，再查这个卖点属于哪档、证据预算多少、周期多长——人体功效试验数万至数十万元、周期 1-3 个月，要进立项预算。

## 绝对红线（任何证据都救不了）
- 医疗用语与暗示疗效：治疗、消炎、抗敏、修复屏障受损（医疗语境）、祛疤、生发、溶脂
- 虚假或绝对化：100% 有效、永久、最安全、第一、排毒
- 明示或暗示对疾病有效：湿疹、痘痘（"祛痘"需特定许可路径，普通品说"改善痘印外观"都要谨慎措辞）
- 贬低他人（拉踩竞品）、利用他人名义担保（"专家推荐"需真实且有证明）
- "药妆""医学护肤品"表述（中国不允许）

## 高频擦边词改写对照
| 想说的 | 风险 | 相对安全的方向（仍需证据） |
|---|---|---|
| 美白淡斑 | 特证才可说 | 提亮肤色、改善暗沉（走普通品宣称路径） |
| 修复屏障 | 医疗暗示 | 维稳、舒缓、增强肌肤耐受（有舒缓功效评价） |
| 抗炎消炎 | 医疗用语 | 舒缓泛红外观 |
| 祛痘 | 需对应路径 | 净颜、改善油痘肌肤外观（谨慎+证据） |
| 7 天见效 | 量化需证据 | 若人体试验确有 7 天数据点，可说并注明试验条件 |
| 婴儿可用/孕妇可用 | 高敏人群宣称需支持 | 通过 XX 测试、无添加 XX（需检测佐证） |

## 检查工作流（给 AI 的执行步骤）
拿到文案后：
1. 逐句提取功效性表述，分类到上表档位
2. 标注每句：✅可说（何种证据下）/ ⚠️需证据确认 / ❌红线
3. 红线句给出保留卖点意图的合规改写
4. 提醒配套义务：宣称依据摘要公开、标签一致性、平台特殊规则（如平台对"最"字、前后对比图的限制）

## 注意事项
- 直播口播是重灾区：主播即兴发挥的"三天白一个度"由品牌担责，投放 brief 里附"禁语清单"
- 前后对比图有专门规范（同光线、未修图、注明周期与个体差异）
- 合规不是一次性的：法规与平台规则更新频繁，重大 campaign 前重新核查
