# 打样评审（Formula Review）

## 何时使用
- 收到 ODM/OEM 或自有研发的打样样品
- 多轮打样之间做结构化反馈
- 配方定版（sign-off）决策

## 评审组织
- 评审人：PM + 3-5 名目标人群内部志愿者（肤质需匹配目标人群！油皮产品让干皮同事评没有意义）+ 研发代表
- 盲测原则：多方案对比时去标签编号，含一个参照物（对标竞品或上一轮样品）
- 试用周期：肤感即时评 + 连续使用 7 天评（刺激性、闷痘等问题即时评不出来）

## 肤感评分表（1-5 分，每项附参照物描述）

| 维度 | 评什么 |
|---|---|
| 外观 | 颜色、均一度、气泡 |
| 香气 | 开盖香 / 上脸香 / 残留香，是否有原料味 |
| 质地 | 稠度、挑起状态、是否符合品类预期 |
| 铺展 | 推开顺滑度、用量经济性 |
| 吸收 | 吸收速度、是否搓泥（**叠加底妆/防晒测**） |
| 残留感 | 黏腻 / 膜感 / 哑光 / 光泽 |
| 即时刺激 | 刺痛、发热、泛红（敏感肌志愿者重点记录） |
| 7 天反馈 | 闭口/闷痘、干燥度变化、持续意愿 |

每项低于 3 分必须写"与参照物的差异描述"，不接受裸分数。

## 给研发的反馈规范
- 汇总为一张表：维度 → 问题描述（带参照物）→ 期望方向 → 优先级（必改/可选）
- 一轮反馈只提"必改"≤3 项——什么都要改等于什么都改不好
- 不指定原料方案（除非营销必须锁定），只描述目标肤感/效果
- 明确本轮是否为最后一轮：进入定版轮后只验证不新增需求

## 定版检查清单
- [ ] 肤感各维度 ≥3.5 且无 7 天不良反馈
- [ ] 核心宣称成分及浓度与营销故事一致（拿到配方表核对）
- [ ] 成本核算过线（原料成本随浓度变化，定版前重新报价）
- [ ] 稳定性测试计划已排期（高温/低温/循环/光照）
- [ ] 安全性评估路径确认（安评报告所需资料工厂能否提供）
- [ ] 与包材相容性测试安排（尤其泵头/滴管与料体）
- [ ] 中试放大风险确认（实验室样 vs 大货肤感可能漂移，要求工厂说明）

## 注意事项
- 内部评审 n 太小，重要单品在定版前加一轮外部目标用户试用（n≥30，回收结构化问卷）
- 打样样品留样封存并编号，大货出问题时是追溯依据
- 警惕"打样惊艳、大货平庸"：定版条件里写明大货一致性验收标准
