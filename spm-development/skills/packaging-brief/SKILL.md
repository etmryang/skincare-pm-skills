# 包材设计 Brief

## 何时使用
- 向设计师/包材供应商下开发需求
- 在候选包材方案间做选型
- 上市后包装迭代（成本优化/口碑问题修复）

## Brief 模板

### 1. 项目背景（半页）
- 产品定位一句话、目标人群、价格带、主要陈列场景（电商详情页首图 / 直播间镜头 / 线下货架 / 开箱短视频）
- **镜头优先级**：线上品牌先问"在手机屏幕 3 秒内能不能看清+记住"，精致细节让位于远景识别度

### 2. 结构需求（给包材商）
- 容量与料体特性：黏度、是否含活性物需避光/隔氧（决定瓶体材质与色号）
- 出料方式：泵头（乳霜泵/精华泵）、滴管、软管、真空瓶——按料体黏度与卫生要求选
- 使用体验硬指标：单手可操作、出料量每泵约 X ml、倒置不漏、旅行携带
- 成本上限（含内外盒）、起订量约束、交期
- 测试要求：跌落、运输振动、密封性、与料体相容性

### 3. 视觉需求（给设计师）
- 设计关键词 3 个 + 反向关键词 3 个（"不要什么"同样重要）
- 竞品货架图：主要竞品包装拼图，指出必须区隔的元素
- 品牌资产约束：logo 用法、品牌色、字体
- 信息层级：首图 3 秒内要读到的三个信息（品名/核心成分/功效词），按优先级排

### 4. 法规文案区（预留，具体内容走 label-review 技能）
- 必标信息清单占位：全成分表、净含量、生产企业与备案人、生产许可证号、限期使用日期、注意事项
- 提醒设计师：**全成分表面积很大**，初稿就要预留，别等审核时打回重排

## 选型决策要点
| 决策 | 权衡 |
|---|---|
| 玻璃 vs PET/亚克力 | 质感与重量运费破损率；直播间灯光下玻璃更出效果 |
| 真空瓶 vs 普通泵瓶 | 活性物稳定性 vs 成本；A醇/VC 类建议真空或铝管 |
| 软管 vs 瓶装 | 低价带亲和 vs 高价带质感；软管余量残留少、成本低 |
| 外盒工艺（烫金/UV/压纹） | 开箱视频表现力 vs 单盒成本；电商件外盒破损率要评估 |

## 时间线提醒（常被低估的关键路径)
瓶型开模 45-90 天；现成模具+丝印/烫金 20-35 天；内外盒印刷 15-25 天。**文案终稿（含合规审核）必须在印刷排产前锁定**——包材返工是新品延期最常见原因。

## 注意事项
- 设计评审用"手机屏幕缩略图"和"1 米外货架照"两种方式看稿，不要只看 A3 打印稿
- 大货前必须签样：颜色以印刷签样为准，屏幕稿会骗人
- 可持续包装（替换芯/减塑）是加分项但有成本，与定价带匹配再做
