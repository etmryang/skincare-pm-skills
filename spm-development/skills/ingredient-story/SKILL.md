# 成分卖点转化（Ingredient Story)

## 何时使用
- 配方定版后开发详情页/直播话术的卖点体系
- 把研发给的技术文档翻译成营销语言
- 检查现有卖点是否有科学与合规硬伤

## 转化链条：五步法

每个核心成分走完这条链：

```
成分事实 → 作用机制 → 可感知效果 → 场景人话 → 证据支撑
```

示例（烟酰胺 5%）：
1. **成分事实**：5% 烟酰胺 + 0.5% 四氢甲基嘧啶羧酸
2. **机制**（一句话，讲给进阶用户）：抑制黑色素向角质细胞转运
3. **可感知效果**（她能验证的）：4 周后肤色更均匀、痘印变淡
4. **场景人话**（讲给小白）："夏天晒完不怕留印"
5. **证据**：人体功效测试报告 / 文献 / 起效浓度对比

**链条断在哪就补哪**：有机制没有可感知效果=自嗨；有人话没有证据=容易被成分党打假。

## 卖点分层结构（详情页/直播通用）

- **第一卖点（记忆点）**：只留一个，7 字内可复述（如"2% 玻色因平价平替"）——用户只会记住一个
- **支撑卖点 2-3 个**：温和性（无 XX 配方）、肤感、搭配性
- **信任状**：功效测试报告、专利号、代工厂背书、皮肤学测试
- **防御性说明**：主动回应社媒聆听发现的 Top 疑虑（闷痘？孕妇？早上能用？）

## 常见硬伤自检清单
- [ ] 浓度真实性：宣称浓度与备案配方一致？"含有"≠"有效浓度"
- [ ] 排名错觉：核心成分在全成分表排位很靠后却当主卖点讲？（成分党会截图）
- [ ] 机制夸大：体外实验/文献数据当成品功效讲？
- [ ] 复配故事：讲"科学复配"但说不出配比逻辑？
- [ ] 借势碰瓷：对标大牌成分但缺同等证据？（"平替"话术有商誉风险，谨慎）
- [ ] 合规红线：出现"修复肌肤屏障（医疗暗示）""7天美白（超出宣称依据）"等表述？→ 转 claim-compliance 技能核查

## 输出模板
| 成分 | 机制（进阶版） | 可感知效果 | 场景人话（小白版） | 证据 | 合规风险 |
|---|---|---|---|---|---|

外加：第一卖点候选 3 个（附取舍理由）、防御性 QA 5 条。

## 注意事项
- 同一卖点准备**双版本话术**（小白版/成分党版），投放素材按人群分发
- 直播话术要给主播"证据道具"：报告截图、对比图、质地展示动作，而不只是形容词
- 不做竞品拉踩式对比表述，广告法风险高
