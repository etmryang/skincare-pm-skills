# 产品概念书（Product Brief）

## 何时使用
- 新品立项，向管理层申请资源
- 向自有研发或 ODM/OEM 工厂下开发需求
- 项目中途对齐"我们到底在做什么"

## 与软件 PRD 的关键差异
- 迭代成本极高：配方定版后改动=重新稳定性测试（1-3 个月）+可能重新备案。**上市前把变更消灭在纸面阶段**。
- 交付物是物理品：配方、包材、备案三条线并行，任何一条都可能成为关键路径。
- 上市窗口刚性：错过大促节点，等半年。

## 概念书模板

### 1. 一页摘要
- 一句话定义：给【谁】的【品类】，通过【核心技术/成分】解决【困扰】，卖点是【差异化承诺】，定价【X 元/规格】
- 上市目标节点与理由（如：10 月上线赶双11 蓄水）
- 首年销量与毛利目标

### 2. 市场依据（各一段，引用数据来源）
- 人群与任务（引用画像/JTBD 结论）
- 赛道规模与增速、竞品对位表（3 个直接竞品：价格/规格/核心成分/主宣称/月销）
- 我们凭什么赢：配方力 / 价格力 / 内容力 / 渠道力，至少占一样

### 3. 产品定义
- **功效定位**：主宣称 + 次宣称（先过法规确认可宣称，标注需要的功效测试类型）
- **成分要求**：核心成分及期望浓度区间、明确禁用清单（香精/酒精/致痘风险成分——按人群定）
- **肤感要求**：质地（啫喱/乳/霜）、吸收速度、残留感、香型方向——用参照物描述（"肤感对标 XX 家 XX"比形容词有效）
- **规格与用法**：容量、早晚用、搭配建议（与产品线其他 SKU 的组合关系）

### 4. 包材方向
- 瓶型/材质/泵头类型、设计关键词、参考图
- 约束：成本上限、起订量、环保要求、运输测试要求

### 5. 商业模型
- 目标零售价、渠道到手价（含大促折扣底线）、COGS 上限、目标毛利率
- 首单量与安全库存假设

### 6. 里程碑与风险
- 关键路径：打样轮次计划 → 配方定版 → 稳定性/安全性测试 → 备案提交 → 包材大货 → 灌装 → 上市
- Top3 风险与预案（常见：功效测试不达标、备案被打回、包材延期）

## 给研发/工厂的沟通要点
- 需求写"要什么效果"，不写"怎么配"——除非你确定要锁某成分做营销故事
- 每轮打样反馈用结构化表格：肤感项逐项打分+对照参照物，避免"感觉不对"这种反馈
- 明确打样轮次上限（一般 ≤3 轮），每轮只改上一轮明确提出的问题

## 注意事项
- 摘要里的一句话定义写不出来=立项不成熟，退回洞察阶段
- 主宣称没确认合规路径前不要定包材文案，返工成本最高的就是印刷品
