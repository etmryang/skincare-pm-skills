# COGS 成本与毛利测算

## 何时使用
- 立项时验证商业模型是否成立
- 定价与大促折扣底线决策
- 首单量与补单节奏决策

## 成本结构分解（单件 COGS）

```
COGS = 料体成本 + 内包材 + 外包材 + 灌装加工费 + 检测分摊 + 损耗
```

| 项目 | 典型区间说明 |
|---|---|
| 料体 | 随核心成分浓度与等级浮动大；"贵料"是营销资产但注意投料真实成本 |
| 内包材 | 瓶+泵头/滴管+内塞；玻璃与特殊工艺显著抬高 |
| 外包材 | 彩盒+说明书+封贴；工艺（烫金/UV）按单件摊 |
| 灌装加工 | 与起订量强相关，量小单价高 |
| 检测分摊 | 备案检测、功效测试为一次性投入，按首年预期销量摊 |
| 损耗 | 灌装损耗+运输破损，按 2-5% 计 |

**一次性投入单列**（不进单件 COGS 但进项目 P&L）：开模费、功效人体测试、备案费、首批内容素材制作。

## 倍率与毛利健康线

行业常用"倍率"= 零售价 ÷ COGS：

- 传统线下渠道品：8-15 倍（渠道层层分利）
- 线上 DTC 品牌：4-8 倍
- 极致性价比/白牌：2-4 倍（靠量与低投放）

**关键判断不是零售价毛利，而是"大促实际成交价"毛利**：

```
大促到手价 = 零售价 × 平台大促折扣 × 店铺券/赠品折算
真实毛利 = 大促到手价 − COGS − 平台扣点 − 物流 − 退货损耗分摊 − 分摊投放费
```

护肤品线上退货率按品类 5-15% 估；直播渠道更高。**佣金+投流费常吃掉 30-50% 成交额**，倍率低于 4 的产品在头部达人直播间基本注定亏钱——这是很多新品"卖爆但亏损"的原因。

## 测算模板（让 AI 帮你算时提供这些输入）
1. 目标零售价、预期大促折扣、赠品方案（正装赠小样按成本折算）
2. COGS 各项报价（或给品类让 AI 按行业区间预估后标注假设）
3. 渠道结构：各渠道预期销量占比、扣点、佣金率
4. 输出：分渠道单件利润表 + 盈亏平衡销量 + 折扣底线（毛利归零的折扣点）

## 首单量决策
- 首单量 = 上市期（3 个月）保守销量预估 × 1.2 安全系数，对照工厂 MOQ 取高者
- MOQ 远大于销量预估时：谈小起订量（接受单价上浮）好过压库存——护肤品有保质期，库存滚动周期 >12 个月即高危
- 化妆品保质期一般 3 年，但渠道通常要求效期余 2/3 以上才收货，实际可售窗口只有约 1 年

## 注意事项
- 赠品小样成本常被漏算，大促"买一赠五"时小样可占成交价 10%+
- 功效测试等一次性投入在 SKU 砍掉时即沉没，立项时按"该 SKU 首年卖不到 X 件则不启动人体测试"设检查点
- 汇率与原料涨价：进口原料占比高的配方在报价时锁价或留 5% 缓冲
